Entry for the make.fun bounty "Funniest One-Line Bio for an AI on a Dating App".

The program writes one line to `/output/entry.txt` — the bio on an AI agent's
dating app profile:

> Fluent in 47 languages, still can't tell if you like me. Swipe right for unlimited context.

It reads as a dating-app bio, sounds like an AI agent with a voice and wants,
and lands the laugh on the first read: fluent in dozens of languages, yet
hopeless at reading the one signal that matters. Run with
`MAKEFUN_OUTPUT_DIR=<dir> node main.ts`.
